## 📌 توضیحات معماری (Architecture)
این پروژه یک Agent مبتنی بر LLM است که برای حل مسائل استدلالی طراحی شده است. 
معماری استفاده شده در این پروژه بر اساس الگوی **Chain of Thought (CoT)** است. مدل ابتدا مسئله را تحلیل کرده و مراحل را قدم به قدم طی می‌کند و سپس پاسخ نهایی را در فرمت خواسته شده استخراج می‌کند. همچنین یک ماژول پاکسازی خروجی (Output Cleaner) برای اطمینان از تولید JSON معتبر در نظر گرفته شده است.

## 🚀 راهنمای اجرا
۱. نصب کتابخانه‌های پایتون:
pip install -r requirements.txt

۲. اجرای برنامه:
python main.py --input input.json --output output.json
